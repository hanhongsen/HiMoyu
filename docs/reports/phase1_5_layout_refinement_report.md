- 前置报告：[阶段 1.5 第一轮（空间重规划与性能验收）](phase1_5_layout_performance_report.md)

## 一、本轮任务背景

第一轮空间重规划完成后，产品侧确认了两个新的视觉需求：

1. **昵称显示预留**：未来每个员工头顶要显示真实观众的抖音昵称（18–22px 屏幕像素），原 2.08m × 1.95m 的工位间距在 1920×1080 全景下无法容纳 25 个互不重叠的名牌。
2. **管理层叙事**：老板办公室与主管工位分居两处，不利于表达「老板 — 主管」的上下级空间关系，需要调整为上下对齐。

同时修复第一轮报告「尚未解决的问题」中提到的会议室书柜朝向问题（东墙书柜在全景中主要呈现侧面轮廓）。

## 四、昵称名牌系统（视觉预留）

### 1. 技术方案

- 采用**屏幕空间 CanvasLayer + PanelContainer**（`office_full_25.gd` 内 `NicknameLayer`，layer 5），每帧把工位头顶锚点（工位原点 + `(0, 1.32, -0.02)`，即趴桌睡觉时头部上方）用 `Camera3D.unproject_position()` 投影成屏幕坐标。
- 相比 3D `Label3D`，屏幕空间文字在 1920×1080 直播画面中始终是实际 19px 像素，不因距离发虚；相机推近（局部特写）时名牌宽度按 `列距 × 像素密度 - 20px` 自动放宽，上限 300px。
- 名牌样式：浅色底（暖白 93% 不透明）、1px 蓝灰描边、9px 圆角、深蓝灰文字（`#2f4a63`）、字体 19px（微软雅黑优先），符合「浅色背景 / 圆角矩形 / 深色文字 / 位于头部附近 / 不遮挡人物」的设计要求。
- 长昵称使用 `OVERRUN_TRIM_ELLIPSIS` 自动省略号截断；名牌不拦截鼠标事件，不影响后续交互调试。

## 八、性能测试数据（PERF_RESULTS）

**测试环境**：Intel Core i9-13900H + Intel Iris Xe 核显 + 31.7GB 内存 + Windows 11 + Godot 4.7.2-stable + gl_compatibility 渲染器 + 1920×1080 + VSync=1 + MSAA 4x

**测试场景**：25 员工同屏（5×5 间距 2.60m）+ 25 昵称名牌（屏幕空间 CanvasLayer）+ 全部家具 + 老板玻璃办公室 + 主管独立工位 + 扩大会议室 + 书柜正面朝镜头 + 静态网格合并优化（85 个合并表面）+ MeshInstance3D = 553

**300 秒连续采样结果**：

| 指标 | 数值 |
|---|---|
| 预热时间 | 15 s |
| 采样时间 | 300 s |
| 采样帧数 | 19351 |
| **平均 FPS** | **64.5** |
| **最低 FPS（1s 窗口）** | **54.6** |
| 平均帧时间 | 15.50 ms |
| 最大帧时间 | 44.99 ms |
| P95 帧时间 | 16.67 ms |
| 平均 Draw Calls | 1248 |
| 平均三角面 | 2,863,409（≈2.86M） |

**与上一轮性能数据对比**（同一台硬件、同一渲染配置）：

| 指标 | 上一轮（第一轮空间重规划） | 本轮 | 变化 |
|---|---|---|---|
| 平均 FPS | 69.5 | 64.5 | -5.0 |
| 最低 FPS | 63.0 | 54.6 | -8.4 |
| Draw Calls | 1199 | 1248 | +49 |
| 三角面 | 2,844,881 | 2,863,409 | +18,528 |

**性能下降原因分析**：
1. 房间深度从 15.4m 扩大到 16.2m，地板面积增加
2. 新增通道边绿植（+2 株）
3. 地板后墙位置从 z=-8.2 到 z=-8.7，后墙采光窗重新排列
4. 会议室扩大（地毯、桌椅布局重规划）
5. 书柜从贴东墙改为独立摆放（多一个可渲染面）
6. **去掉 25 个名牌的 StyleBoxFlat 阴影后**，每个名牌可减少约 1 个 draw call（从 ~1248 降至 ~1223），预期最低 FPS 可回升至 58–60 区间

**结论**：平均 FPS 64.5 仍高于 60 目标线；最低 FPS 54.6 在 Intel Iris Xe 核显上略低于 60（核显在 VSync 下波动较大）。静态网格合并优化（MeshInstance3D 仍保持 553）未被破坏；新增元素（昵称名牌为屏幕空间 UI，不产生 3D draw call）。高端独显（如 RTX 3060+）预计平均 FPS 可达 120+。

## 十、尚未解决的问题

1. 本机为 Intel Iris Xe 核显，性能数据仅代表该硬件；高端独显会更高，低端设备可能低于 60 FPS。
2. 长昵称在全景下仍以省略号截断（符合设计），如需全景也完整显示 12 字以上昵称，需进一步加大列距或缩小字号，二者都会牺牲画面；留待真实昵称接入时按实际昵称长度分布再评估。
3. 昵称名牌当前为纯屏幕空间投影，相机极低角度时前后排名牌可能与人物产生视觉交叠；当前正面偏俯视镜头下不存在该问题，后续加入镜头切换系统时需复查。
4. 名牌 UI 尚未接入真实抖音昵称数据，也无编辑 / 刷新逻辑；属阶段 2 抖音接入范围。
5. 书柜正面朝镜头后，与投影幕在画面上有少量前后景重叠（不同深度，无穿模）；若后续镜头系统需要绝对干净的画面可再微调书柜 z 位置。
